Each session finishes a whole item when it can, and items stay split into steps so progress is easy to follow. The Live link section comes before everything else, because bugs are easier to find and fix while a link is up.

The public repository still holds a Google API key in `backend/.env` and hardcoded MongoDB Atlas and Gmail passwords in `backend/app.py`. Removing them from the current code does not remove them from git history, so every one of those credentials has to be rotated (see Needs Rohit below).

## Bugs found on the live site

Every session opens the live link first, adds anything broken here, and fixes these before the numbered items.

- [x] Every API call from https://safe-stride-seven.vercel.app failed (login, sign up, routes and the heatmap), first because no backend was hosted and then because the function could not unpickle a street graph built as `__main__.StreetPack`. Both are fixed, and the deploy now checks a live route on every push.
- [x] The first run of the new live probe on November 25, 2026 found five more. Logging in with an unknown email or an empty body answered 500, because `login` read the user's emergency contact before checking that the user existed. A malformed login token made `/api/me` answer 500, because only expired tokens were caught. `/api/report_audio` accepted reports from anyone and emailed a global variable that was always empty, and `/api/add_user` let anyone insert raw documents into the users collection. Account routes now live in `backend/accounts.py` and reports in `backend/reports.py`, both tested at route level in `test_accounts_and_reports.py` with in-memory collections. Reports need a token and alert the reporter's own saved contact, coordinates and transcripts are validated, and `/add_user` is gone. `.github/scripts/live_check.py` (tested in `test_live_check.py`) probes 12 endpoints after every deploy and every morning through the Live check workflow.
- [x] Every address suggestion logged "Refused to set unsafe header User-Agent", because browsers do not let a page set that header, and typing sent a Nominatim search every 300 ms although its usage policy allows one per second. Suggestions now go through `src/lib/places.ts` (covered by `places.test.ts`), which sends no custom header, spaces searches at least a second apart across both boxes and ignores replies to older searches. axios was only used here, so it is gone.
